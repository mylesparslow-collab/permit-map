# Permit Map (embeddable)

A drop-in `<permit-map>` web component: new California building permits as leads for a contractor's trade, on a map,
with status, follow-ups, notes, CSV/calendar export and webhooks. Built for MLP Consults clients.

Live demo: https://mylesparslow.com/permit-map/

```html
<script src="https://mylesparslow.com/permit-map/permit-map.js" defer></script>
<permit-map trade="countertops" center="34.0195,-118.4912" radius="10" business-name="Your Business"></permit-map>
```

Permit data comes from public city and county records (sources and dates are listed inside the map under "About the data").
Maps © OpenStreetMap contributors. Outlines: US Census Bureau TIGERweb.
